Política de privacidad

Última actualización: 7 de octubre de 2026

Esta política explica cómo Respira Fácil trata los datos utilizados para crear cuentas, realizar evaluaciones y consultar su historial.

1. Responsable y contacto

El responsable de esta aplicación es Rodrigo Estrada. Para consultas sobre privacidad o solicitudes relacionadas con tus datos, escribe a Contacto de privacidad.

2. Datos que utiliza la aplicación

  • Datos de registro: nombre, apellido, correo electrónico y contraseña para acceder a la cuenta.
  • Datos de evaluación: peso y altura para calcular el índice de masa corporal (IMC), y respuestas sobre dificultad para respirar, tos, silbidos y opresión en el pecho.
  • Historial: resultado, fecha y hora de las evaluaciones asociadas a tu cuenta.

3. Finalidad del tratamiento

Estos datos se utilizan para gestionar tu cuenta, procesar las evaluaciones, mostrar sus resultados y conservar tu historial. El correo electrónico también se utiliza para gestionar solicitudes de recuperación de contraseña.

Las respuestas sobre síntomas y el IMC se envían al servicio de evaluación para obtener el resultado.

4. Correos y uso de Gmail API

La integración con Gmail API está destinada al envío de enlaces de recuperación de contraseña desde una cuenta del administrador, autorizada por su titular. El permiso solicitado es gmail.send.

Esta integración no solicita acceso al buzón de Gmail de los usuarios de Respira Fácil ni permiso para leer sus mensajes. Para enviar el correo de recuperación, Google procesa la dirección del destinatario y el contenido del mensaje, incluido el enlace de recuperación.

5. Servicios utilizados

La aplicación utiliza Netlify para alojar la interfaz, Render para los servicios del backend y de evaluación, y Neon para la base de datos. El envío de correos mediante Gmail API utiliza los servicios de Google. Estos proveedores procesan la información necesaria para prestar sus respectivos servicios, y su infraestructura puede encontrarse fuera de Perú.

6. Almacenamiento en el navegador

Respira Fácil utiliza almacenamiento local del navegador para conservar información del usuario que inició sesión y permitir la navegación dentro de la aplicación.

7. Conservación y solicitudes sobre tus datos

La cuenta y su historial se conservan para permitir el uso de la aplicación. Puedes solicitar información, corrección o eliminación de tus datos mediante el correo de contacto. Para atender una solicitud podrá ser necesario verificar que eres el titular de la cuenta.

8. Alcance de los resultados

Los resultados de Respira Fácil son orientativos y no sustituyen una evaluación ni un diagnóstico profesional.

9. Cambios en esta política

Los cambios en el tratamiento de datos se reflejarán en esta página junto con su fecha de actualización.
